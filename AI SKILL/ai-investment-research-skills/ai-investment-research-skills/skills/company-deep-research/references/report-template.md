# Institutional-quality company report template

Use this as a decision-oriented structure. Merge immaterial sections, but preserve the analytical contracts. Put supporting detail in appendices when the main report becomes difficult to scan.

# [Company] deep research report

**Cutoff date and time:** YYYY-MM-DD HH:MM TZ  
**Audience:** investors / VC-PE / industry researchers  
**Decision question:** one sentence  
**Investment horizon:** explicit  
**Company status:** public / private / subsidiary  
**Currency and units:** explicit  
**Disclaimer:** independent research; not personalized investment advice

## 1. One-page decision summary

Include an at-a-glance table:

| Item | Current/observed | Base view | Range or key sensitivity |
|---|---:|---:|---:|
| Price / implied equity value | | | |
| Enterprise value | | | |
| Normalized earnings or FCF | | | |
| Fair-value / expectation range | | | |
| Implied return or valuation gap | | | |

Then state:

- conclusion, stance, confidence, and time horizon;
- three strongest reasons to believe and three strongest reasons to doubt;
- what the current valuation requires operationally;
- 12-24 month catalysts and signposts;
- thesis breakers and the next evidence that would change the view.

## 2. Scope, method, and limitations

- cutoff, perimeter, exclusions, and source plan;
- definitions of `[事实]`, `[公司口径]`, `[计算]`, and `[判断]`;
- material unavailable information, proxies, and resulting confidence limits;
- actual-versus-estimate notation, for example `2025A`, `2026E`, and scenario years.

## 3. Company perimeter, ownership, and capital structure

- investable entity versus brand and operating subsidiaries;
- ownership, control, related parties, share classes, options, convertibles, and diluted shares;
- minority interests and which earnings or assets belong to outside shareholders;
- financing history and capital-allocation record.

## 11. Valuation and embedded expectations

### Public-company branch

- date-specific price, diluted shares, market cap, net debt, minority interests, and enterprise value;
- at least two appropriate independent methods: DCF, SOTP, trading comparables, transaction comparables, or asset value;
- reverse valuation showing growth, margin, reinvestment, and timing implied by the current price;
- sensitivity table and reconciliation from enterprise to equity and per-share value;
- fair-value or expectation range, not a falsely precise point.

### Private-company branch

- round or secondary date, security type, primary versus secondary, post-money/equity-value meaning;
- preferences, dilution, liquidation waterfall, option pool, illiquidity, and financing needs where known;
- scenario, transaction, or SOTP valuation with explicit return and exit assumptions.

## 12. Governance, regulation, and capital allocation

Assess control, board independence, incentives, key-person risk, related parties, audit issues, capital-allocation history, licenses, litigation, safety, environment, export controls, subsidies, and geopolitical dependencies.
